## 各レベルの詳細計画

### Level 0: 関数の世界への入口

#### 0-1. 「変数」と「代入」の本質

**ビジュアライズ: 変数マシン**
- 箱（変数）にボールを入れるアニメーション
- x = 3 を入れると、箱が光って「3」を保持
- 「変数は名前付きの入れ物」を直感的に

**インタラクティブ演習: 変数トレース**
- コード的な代入の流れを視覚化
  ```
  x ← 5
  y ← x + 2
  z ← x × y
  ```
- 各ステップで値がどう伝播するかアニメーション

#### 0-2. 「関数」とは何か

**ビジュアライズ: 関数マシン（ブラックボックス）**
- 入力口と出力口がある機械
- 数字を入れると、変換されて出てくる
- 「同じ入力には必ず同じ出力」を体感

**インタラクティブ: 関数当てゲーム**
- 隠された関数（例: f(x) = 2x + 1）
- いろんな値を入れて出力を見る
- 規則性を推理して関数を当てる

#### 0-3. 座標平面とグラフの誕生 [実装済み]

**ビジュアライズ: レーザー刻印グラフ**
- スライダーで x を -5 → 5 に動かす
- 各 x に対して f(x) を計算（計算過程も表示）
- (x, f(x)) の点がレーザーのように打たれていく

---

### Level 1: 一次関数（土台固め）

#### 1-1. 傾きと切片の意味

**ビジュアライズ: 傾きシミュレータ**
- y = ax + b の a, b をスライダーで変化
- a を変えると線が回転（原点ではなくy切片中心）
- b を変えると線が平行移動
- 「傾き = 1進んだら何上がる？」を視覚化

**インタラクティブ: 傾き体感ゲーム**
- 2点を与えられる
- その2点を通る直線の傾きを当てる
- 間違えると「その傾きだとこうなるよ」と表示

#### 1-2. 一次関数の応用感覚

**ビジュアライズ: 交点探索**
- 2本の直線が動的に動く
- 交点座標がリアルタイム表示
- 「連立方程式 = 交点を求めること」を視覚的に

---

### Level 2: 二次関数

#### 2-1. 放物線の誕生

**ビジュアライズ: 二乗の意味**
- x → x² の変換をステップ表示
- 負の数が正になる瞬間を強調
- 「だから左右対称になる」を納得

#### 2-2. 標準形のパラメータ [実装済み]

**ビジュアライズ: y = a(x-p)² + q マスター**
- 3つのスライダー: a, p, q
- 各パラメータの「役割」を分離して理解

**インタラクティブ: 頂点当てゲーム**
- グラフを見て頂点座標を答える
- 式を見て頂点座標を答える
- 逆に頂点座標から式を作る

#### 2-3. 平方完成の意味

**ビジュアライズ: 平方完成アニメーション**
- y = x² + 4x + 3 を変形
- 式の変形と同時にグラフが動く
- 「なぜこの変形をするのか」= 頂点を見つけるため

**インタラクティブ: 補完パズル**
- x² + 6x + □ = (x + △)² の形式
- 面積図で「何が足りないか」を視覚化

#### 2-4. 判別式の本質

**ビジュアライズ: 放物線とx軸の関係**
- D = b² - 4ac のスライダー
- D > 0: 2点で交わる
- D = 0: 接する
- D < 0: 交わらない（解なし）

---

### Level 3: 三角関数

#### 3-1. 単位円との出会い [実装済み]

**ビジュアライズ: 回転する点**
- 単位円上を点が回転
- その点の x座標 = cosθ、y座標 = sinθ

#### 3-2. 波の誕生 [実装済み]

**ビジュアライズ: 円から波へ**
- 単位円の回転と同期
- y座標の軌跡が sin 曲線として現れる
- 「円運動の影が波になる」

#### 3-3. パラメータの意味

**ビジュアライズ: y = A sin(Bx + C) + D**
- A: 振幅（波の高さ）
- B: 角周波数（波の詰まり具合）
- C: 位相（横シフト）
- D: 中心線（縦シフト）
- 4つのスライダーで完全制御

**インタラクティブ: 波形マッチング**
- 目標の波形が表示される
- パラメータを調整して一致させる

#### 3-4. 三角関数の合成

**ビジュアライズ: 波の足し算**
- sin と cos の波を同時表示
- 合成波が生成される様子

---

### Level 4: 融合問題（最終ボス）

#### 4-1. 三角関数を含む二次関数

**例題: sin²θ の二次関数化**
- t = sinθ と置換する意味
- t の範囲が -1 ≤ t ≤ 1 になる理由
- 二次関数の頂点と定義域の関係

**ビジュアライズ: ダブルグラフ**
- 左: t = sinθ のグラフ（t の範囲確認）
- 右: f(t) = t² - 2t + 3 のグラフ（二次関数）
- 定義域制限がかかる様子をアニメーション

#### 4-2. 二次関数と三角関数の方程式

**インタラクティブ: 解の個数**
- 放物線と直線/三角関数の交点
- パラメータで解の個数が変化

## 技術決定事項

- **進捗管理**: ユーザーごとにURL発行（匿名ID方式）
- **スタイリング**: ダークモードベース
- **フレームワーク**: Vanilla TypeScript（Vite）

## バックエンド拡張計画

### 進捗保存API

```typescript
// ユーザー作成（URL発行）
POST /api/user
→ { id: "abc123", url: "/u/abc123" }

// 進捗保存
POST /api/user/:id/progress
{ level: 2, section: 3, completed: true }

// 進捗取得
GET /api/user/:id/progress
→ { levels: { 0: [1,2,3], 2: [1,2] } }
```

- Cloudflare KV または D1 を使用
- キー: `user:{id}:progress`
